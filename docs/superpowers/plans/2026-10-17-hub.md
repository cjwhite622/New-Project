# The Hub implementation plan

Goal: deliver a runnable Phase 0/1 desktop application faithful to the attached vision.

Architecture: local React UI, Node 24 loopback API, business SQLite and separate personal SQLite, Electron installer. Execute in this existing `work` branch in the current session under the user's authorization to improve and build.

Spec: `docs/superpowers/specs/2026-10-17-hub-design.md`.

## Global constraints

- No fabricated operating results or implied live account connections.
- First run must finish the resumable interview before agent activation.
- API and operating budgets are hard limits; reserve before spending.
- Life Coach content never reaches business storage, audit, or exports.
- No credentials in source, logs, renderer storage, or exported business data.

## Review focus

1. Duplicate/import/replay inputs must produce at most one side effect.
2. Pausing during a paid request must abort and prevent subsequent jobs.
3. Concurrent calls must not outrun budgets through unchecked reservations.
4. Missing keys or ambiguous provider failures must never appear successful.
5. Manual income must remain unverified in every screen and export.
